# Kayyum Fincan Okuyucu ☕

## Bu Nedir?

Bu proje, modern Türkiye'nin en acil ihtiyacı olan **resmi kahve falı** sorununu çözmek üzere tasarlanmıştır. Artık fincanlarınızı rastgele yorumlayan amcasınız değil, **atanmış kayyum seviyesinde** ciddi bir algoritma yorumlayacak.

Her fincan, bir mahkeme kararı kadar bağlayıcıdır. Yorumlar çıktıktan sonra itiraz hakkınız yoktur, çünkü sistem zaten sizin adınıza itiraz etmiş ve reddetmiştir.

## Özellikler

- %100 resmi dil
- Hiçbir şey anlamayan ama çok ciddi görünen yorumlar
- Otomatik "yarın gelin" modu
- Gizli bir şey yok, her şey şeffaf (değil)

## Kurulum

```bash
pip install -r requirements.txt  # aslında gereksinim yok ama resmi olsun diye var
python fincan_okuyucu.py
```

## Kullanım

Fincanınızı ters çevirin, bekleyin, sonra programı çalıştırın. Şekilleri tarif edin. Sistem size hayatınızı yönetecek kararlar verecektir.

## Uyarı

Bu yazılım hiçbir şekilde gerçek bir kayyum değildir. Gerçek kayyumlar daha yavaş çalışır.
